# Keyboard shortcuts

Press ⌘/ in Immage for this list. On Windows and Linux, ⌘ is Ctrl, ⌥ is Alt
and ⇧ is Shift. Most keys are the ones mainstream editors use.

The File, Edit, Photo, View and Help menus show each command's shortcut
beside it, so the menus are another place to find a key. See
[The workspace](workspace.md#menus) for where the menus appear.

Keys do nothing while you type in a text field or while a dialog is open.
A focused menu keeps its arrow keys, Space and Enter for choosing.

| Key | Action |
| --- | --- |
| ⇧⌘I | Import photos |
| ⇧⌘E | Export |
| ⌘P | Print |
| S | Soft proof on or off, against the Print panel's printer profile |

| ⌘/ | Keyboard shortcuts |
| ⇧⌘P | Performance overlay |
| ⌘Z | Undo |
| ⇧⌘Z | Redo |
| ⇧⌘C | Copy settings |
| ⇧⌘V | Paste settings |
| ⌥⌘V | Paste the previous photo's settings |
| ⌘' | Create virtual copy, of every selected photo |
| ⌃H | HDR Merge, of the selected raws (Ctrl+H on Windows and Linux) |
| ⌃M | Panorama Merge, of the selected raws (Ctrl+M on Windows and Linux) |
| ⌘A | Select every photo shown |

## View

| Key | Action |
| --- | --- |
| F | Full screen preview in the editor (F or Esc leaves); in the grid, the Loupe of the photo under the pointer or the selection |
| L | Next canvas: dark, neutral gray, white |
| Tab | Hide or show the side panels |
| ⇧Tab | Hide or show the side panels and filmstrip |
| Z | Fit or the navigator's zoom (100% until another is picked) |
| ⌘= ⌘- | Zoom in or out: fit, fill, 1:1, 2:1, 3:1, 4:1 |
| Click | Zoom to 100% there, or back to fit |
| Scroll | Zoom around the pointer (a brush in hand: its size) |
| Space-drag | Pan a zoomed-in photo, in any tool |
| \ | Before |
| Y | Next before / after view: side by side, split left / right, split top / bottom |
| C | Compare with another photo (← → step it, Esc leaves) |
| J | Show or hide shadow and highlight clipping |
| H | Next scope: histogram, waveform, RGB parade, vectorscope, waveform + vectorscope (⇧H back) |
| I | Cycle the info over the photo: file and capture, exposure and lens, none |

In full screen preview, Z, ⌘= ⌘-, Y, X, I, L, \, 0-9 and ← → still work.

## Photos

| Key | Action |
| --- | --- |
| ← → | Previous or next photo |
| 0 - 5 | Rating, for every selected photo |
| 6 - 9 | Red, yellow, green or blue label, for every selected photo |
| X | Reject |
| ⇧⌘G | Critique with Gemini the photo under the pointer or the selection, in the grid |
| ⇧P | Show People (the faces in your photos), from any view, or go back to the grid. In it: arrows move, N or a letter names the selected groups, ⌘A selects all, M merges, I ignores, F2 renames, Backspace marks "not a face" or "not them" |
| ⇧F | Show or hide the face boxes on the open photo in the editor (when People is on) |
| ⇧S | In the grid: show the photos as Scenes (a timeline of bursts), or go back to the grid |
| A X U | In Scenes: accept, reject or clear the scene's best frame (⇧ for the whole scene); in a scene's preview, the frame shown |
| N ⇧N | In a scene's preview: the next or previous scene |
| Z | In a scene's preview: 100% on the frame's sharpest region, and back to Fit (⇧Z: 100% at the center) |
| S M | In a scene's preview: split the scene at this frame, or merge it with the next scene |
| P R B | In the Loupe of a reviewed Auto cull: keep the photo, reject it, or make it the best of its set (the preview of a photo in the review) |
| ⌘-click | In the filmstrip: add a photo to the selection, or take it out |
| ⇧-click | In the filmstrip: select the run from the last clicked photo |
| ⌥1 - ⌥9 | Open saved filter 1 to 9 (Find's saved filters, in list order) |
| G | Grid view of the folder, as the Grid button at the left of the toolbar under the filmstrip and the rail's Library button (G or Esc goes back) |
| ⌘= ⌘- | In grid view: larger or smaller thumbnails |
| Pinch, ⌘-scroll | In grid view: resize the thumbnails smoothly |

## Adjustments

| Key | Action |
| --- | --- |
| W | White balance picker (Esc cancels) |
| Double-click | A slider or its name: reset it |
| Double-click | A slider's value: type one |
| Scroll | Over a slider: nudge it, when Preferences allows |
| ⌥-drag | Some sliders: show what they affect |
| ⌥-click | A tool panel's title on the right: open it alone (in Focus mode, alongside the others). Library cards ignore it |

## Masks

| Key | Action |
| --- | --- |
| K | Brush |
| M | Linear gradient |
| ⇧M | Radial gradient |
| ⇧J | Color range |
| ⇧Q | Luminance range |
| [ ] | Brush size |
| Scroll | With the brush: its size; ⇧ its feather |
| ⌥-drag | Brush away |
| O | Show or hide the overlay |
| Esc | Put the tool down |
| Space-drag | Pan a zoomed-in photo, without painting or moving a mask |

The mask keys work from anywhere: they open Masks with that tool.
